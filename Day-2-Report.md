# Day 2 – Linux Authentication Log Analysis

## 1. Objective
To analyze Linux authentication logs and understand user login activities, successful sessions, failed login attempts, and SSH authentication events.

## 2. Tools Used
- Kali Linux
- Terminal
- journalctl
- grep
- last
- systemctl

## 3. Analysis Performed
- Analyzed sudo authentication logs.
- Checked failed login attempts.
- Reviewed successful session records.
- Examined login history.
- Checked SSH service status.
- Searched for SSH authentication events.

## 4. Findings
- Sudo authentication records were found.
- No matching failed authentication events were found in the current boot logs.
- Successful session records were identified.
- Local login history was reviewed.
- SSH service was installed but inactive.
- No matching SSH authentication events were found in the current boot logs.

## 5. Conclusion
Linux authentication logs were successfully collected and analyzed. The available logs did not show matching failed login or SSH authentication events during the current boot period.
